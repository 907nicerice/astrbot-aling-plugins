# Memory System

阿绫的记忆系统分为长期记忆、短中期连续性和当前生活状态。

## 长期记忆

由 `aling_memory` 负责。适合保存用户偏好、稳定关系设定、长期小细节和可复用的回忆线索。

## 短中期连续性

由 `inner_continuity` 负责。适合保存最近几轮或最近几天仍有余温的互动、未闭合话题和情绪状态。

## 当前生活状态

由 `shared_life_context` 负责。适合保存今天正在做什么、能量水平、当前活动和短周期生活上下文。

## 注意

记忆不是聊天记录复制，也不是上下文压缩的替代品。记忆插件应提供被筛选、被压缩、与当前对话相关的少量线索。
